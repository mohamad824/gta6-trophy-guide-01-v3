# Neon Palm — GTA VI Trophy Guide & Tracker

An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a cited step-by-step guide in our own words, a 7-stage roadmap to the platinum, missable flags, and a checklist that saves in the browser and exports/imports as JSON.

## Run locally

```sh
python3 -m http.server 8123 --directory app
```

Then open http://localhost:8123/index.html in desktop Chrome. The guide works fully offline — no network requests at run time.

## Build the submission dossier

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
